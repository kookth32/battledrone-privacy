배틀드론 개인정보처리방침

운영자: Baby Cat Games · 개인정보 보호책임자: 대표 · 문의: babycatgames@naver.com · 시행일: 2026년 11월 26일

Baby Cat Games(이하 "운영자")는 모바일 게임 「배틀드론」(이하 "게임")을 이용하는 분의 개인정보를 「개인정보 보호법」에 따라 처리합니다. 이 방침은 구글 플레이로 배포하는 텀블벅 데모판에 적용됩니다.

1. 처리하는 개인정보

회원가입 때 입력아이디, 비밀번호, 이메일 주소
게임을 하면서 생기는 정보게임 기록(드론·아이템·골드·코어·전직·강화·퀘스트·싱글 캠페인 진행·경기 결과·매너 온도), 서버 작동 기록(접속 IP 주소, 접속 시각, 요청 내용)
서버를 거쳐 전달만 하는 정보멀티 대기실 채팅 내용 — 같은 방 이용자에게 전달만 하고 저장하지 않습니다.
채팅을 신고할 때신고한 사람과 신고 대상의 아이디, 신고한 채팅 내용, 신고 시각 — 운영자가 확인하고 조치하는 데만 씁니다.
차단 목록내가 차단한 아이디 — 휴대폰 안에만 저장하고 서버로 보내지 않습니다.
부정 이용 방지접속을 막은 IP 주소, 짧은 시간에 거듭 가입하는 것을 막기 위한 마지막 가입 IP 주소와 시각(서버 메모리에만 두고 따로 저장하지 않음)
휴대폰 안에만 저장"아이디 저장"을 켠 경우의 아이디, 게임 설정, 빠른 표시를 위한 싱글 진행 사본(원본은 위 게임 기록) — 비밀번호는 저장하지 않음

위치 정보, 연락처, 사진, 광고 식별자 등 휴대폰의 다른 정보는 수집하지 않습니다.

2. 처리 목적

  • 회원 확인과 로그인, 계정 관리
  • 게임 서비스 제공: 멀티 대전 연결, 게임 기록 저장, 보상 지급
  • 부정 이용 방지(접속 차단), 채팅 신고 확인과 조치, 오류 확인, 문의 응대

3. 보유 기간과 파기

  • 계정 정보와 게임 기록: 계정을 삭제하면 바로 서버에서 지웁니다. 지운 기록은 되돌릴 수 없습니다.
  • 서버 작동 기록(접속 IP·시각·요청 내용): 30일 보관 후 자동으로 지웁니다.
  • 접속을 막은 IP 주소: 차단을 풀 때까지 보관합니다. 마지막 가입 IP 주소와 시각은 서버를 다시 시작하면 사라집니다.
  • 채팅 신고 기록: 운영자가 처리한 뒤 90일이 지나면 지웁니다. 신고한 사람이나 대상이 계정을 삭제하면 바로 지웁니다.
  • 텀블벅 데모 서비스가 끝나면 데모 서버의 모든 계정과 기록을 지웁니다.

4. 제3자 제공·처리 위탁·국외 이전

개인정보를 다른 사람이나 회사에 제공하지 않고, 처리를 맡기지 않으며, 국외로 옮기지 않습니다. 게임 서버는 운영자가 직접 운영합니다. (앱 설치·업데이트 과정의 정보 처리는 Google Play의 개인정보처리방침을 따릅니다.)

5. 광고

데모판에는 광고가 없고 광고 식별자를 수집하지 않습니다.

6. 계정 삭제 방법

게임 안에서 바로 삭제
  1. 게임을 켜고 로그인 화면에서 삭제할 계정의 아이디와 비밀번호를 입력합니다.
  2. 화면 왼쪽 아래 "계정 삭제"를 누릅니다.
  3. 확인 창에서 "예"를 누르면 계정과 모든 게임 기록이 바로 삭제됩니다.
앱을 지웠거나 비밀번호를 잊은 경우

babycatgames@naver.com으로 제목 "배틀드론 계정 삭제 요청", 본문에 아이디와 가입한 이메일 주소를 적어 가입한 이메일로 보내 주세요. 본인 확인 후 7일 안에 삭제하고 답장드립니다.

계정은 두고 일부 기록만 지우고 싶은 경우

babycatgames@naver.com으로 제목 "배틀드론 데이터 삭제 요청", 본문에 아이디와 지우고 싶은 기록(예: 경기 기록, 채팅 신고 기록)을 적어 가입한 이메일로 보내 주세요. 본인 확인 후 7일 안에 지우고 답장드립니다. 로그인에 꼭 필요한 정보(아이디·비밀번호·이메일)까지 지우려면 위의 계정 삭제를 이용해 주세요.

지워지는 정보: 아이디·비밀번호·이메일, 드론·아이템·골드·코어·전직·강화·퀘스트·캠페인 진행·경기 기록·매너 온도, 이 계정이 하거나 받은 채팅 신고 기록 등 계정에 딸린 모든 기록.
남는 정보: 서버 작동 기록(접속 IP·시각)은 30일 뒤 자동으로 지워집니다.

7. 이용자의 권리

언제든지 자신의 개인정보를 열람·정정·삭제하거나 처리를 멈추도록 요청할 수 있습니다. 계정 삭제는 게임 안에서, 그 밖의 요청은 babycatgames@naver.com으로 보내 주세요. 10일 안에 처리 결과를 알려 드립니다.

8. 만 14세 미만

만 14세 미만은 법정대리인의 동의가 필요하므로 데모판에 가입할 수 없습니다. 만 14세 미만의 계정으로 확인되면 삭제합니다.

9. 안전을 위한 조치

  • 게임 서버와 데이터베이스는 운영자 한 사람만 다룰 수 있게 관리합니다.
  • 데이터베이스는 운영자 계정과 비밀번호로만 접속할 수 있습니다.
  • 안내: 데모판은 통신 구간 암호화를 아직 적용하지 않았습니다. 다른 서비스에서 쓰는 비밀번호를 쓰지 마세요. 정식 출시 전에 암호화를 적용할 예정입니다.
